# Changelog

## 1.0.0

- Define the seekable, append-only Arctic container format v1.
- Add independently compressed binary and NBT chunk schemas.
- Add a lazy Minestom `ChunkLoader` for Java 25.
- Add dual-superblock crash recovery, checksums, checkpoints, tombstones, and compaction.
- Persist blocks, biomes, light, block entities, heightmaps, and extension NBT.
